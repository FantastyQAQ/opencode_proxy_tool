# OpenCode 代理配置工具

把 `opencode_proxy.py` 的功能移植为图形界面：自动探测本地代理，把代理环境变量写入
OpenCode 后台服务与用户环境，重启服务并验证，全程通过日志面板实时输出探测过程、
每个配置项的写入状态与验证结果。原理与参数对应关系见根目录 `README.md`。

主要功能：

- 开始配置：自动探测可用代理 → 写服务环境变量 → 写用户环境变量 → 重启服务 → 三层验证
- 仅探测：只探测可用代理并展示，不写入任何东西
- 撤销代理：清空服务环境变量与用户环境变量（含小写键、`NODE_EXTRA_CA_CERTS`），按选项重启
- 仅演练：只打印将要执行的命令，不写入、不重启、不验证
- 代理地址留空自动探测，也可显式指定；常见端口下拉一键填入
- CLI 路径留空按候选目录自动定位，也可浏览指定；企业 SSL 拦截时可配 CA 证书
- 勾选「写入用户环境变量」写 `HKCU\Environment` 并广播 `WM_SETTINGCHANGE`
- 右下角显示代理转发配置状态与本轮运行时长
